# KHH Seoul 🎤

KHH演出信息聚合平台

🔗 **在线访问**: [khh-seoul.vercel.app](https://khh-seoul.vercel.app)

## 项目

本项目可以为身处或计划前往韩国的KHH乐迷提供当地的演出信息，旨在为所有khh乐迷收集和展示所有通常仅在KHH核心乐迷群体内部流通————像依赖个人社交账号的临时发布或本地社群的口耳相传等的演出信息。这些信息总是缺乏统一的公开获取渠道。
相较于公开售票的正式演出，地下场次的信息获取门槛更高，往往仅为长期浸润于KHH文化圈层的资深乐迷所掌握。市面上的演出平台也多仅覆盖正式票务演出，地下场景存在明显的信息空白。

KHH Seoul 致力于填补这一空白，让任何关注韩国嘻哈的乐迷，无论身处何地，都能快速通过KHH Seoul查询到首尔近期（当天/本周）的hiphop演出，享受音乐充斥的美妙夜晚。

## 核心功能

- 📅 演出信息展示，按"今晚"与"近期"分类呈现
- 🔍 多维度筛选：时间、区域（홍대/이태원/강남）、票价
- 🏢 场地与艺人信息结构化管理
- 🔐 管理员后台：演出信息的增添和修改
